# First-day base rates

- US IPOs averaged about a 19% first-day return from 1980 to 2025, and 29.3% in 2025.
- Large-cap IPOs averaged only about 10%.

Source: Jay Ritter, University of Florida, https://site.warrington.ufl.edu/ritter/ipo-data/

Treat these as the base case to argue against, not a forecast. Add more rows to `large_ipos.csv` (Arm, Reddit, CoreWeave, Figma) with day-5 closes if your agent needs a fade estimate.
